# Archiving Projects

Project owners can archive a project on PyPI when they do not expect to maintain it further. The archived status tells users that they should not expect future releases, maintenance, or security fixes.

Archiving is a status notice, not deletion. The project remains on PyPI and users can still install its existing releases. Archiving does prevent new files from being uploaded to the project.

## Before archiving

Consider making a final release before archiving. Update the project description with the reason for archiving and any information that will help users choose a maintained alternative or continue using the existing releases safely.

## Archive a project

1. Sign in to the account that owns the project.
2. Open the project’s settings page on PyPI.
3. Scroll to the **Project archival** section near the bottom of the page.
4. Review the warning that archiving prevents new uploads, then follow the controls in that section to archive the project.

After archiving, the project page displays an archived notice. Existing releases remain available for installation. Project owners can unarchive the project if its status changes.

For background on the feature, see [PyPI now supports project archival](https://blog.pypi.org/posts/2025-01-30-archival/).
