# PyPI Statistics

You can analyze PyPI project/package metadata and [download usage statistics](https://packaging.python.org/guides/analyzing-pypi-package-downloads/) via our public dataset on Google BigQuery.

[Libraries.io provides statistics for PyPI projects](https://libraries.io/pypi) ([example](https://libraries.io/pypi/twine/), [API](https://libraries.io/api)) including GitHub stars and forks, dependency tracking, and [other relevant factors](https://docs.libraries.io/overview#sourcerank).

For recent statistics on uptime and performance, see [our status page](https://status.python.org/).
