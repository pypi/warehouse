# PyPI Roadmap

Changes to PyPI are generally announced on both the [pypi-announce mailing list](https://mail.python.org/mailman3/lists/pypi-announce.python.org/) and the [PyPI blog](https://blog.pypi.org). The PyPI blog also has an [RSS](https://blog.pypi.org/feed_rss_created.xml) feed.

When PyPI maintainers are deploying new features, at first we mark them with a small "beta feature" symbol to tell you: this should probably work fine, but it's new and less tested than other site functionality.

Currently, no features are in beta.
