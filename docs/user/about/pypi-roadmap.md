# PyPI Roadmap

Major changes to PyPI are generally announced on the [pypi-announce mailing list](https://mail.python.org/mailman3/lists/pypi-announce.python.org/) and/or the [PyPI blog](https://blog.pypi.org). 

The PyPI blog also has an [RSS](https://blog.pypi.org/feed_rss_created.xml) feed.
