# Getting Help

!!! note
    All users requesting help from the PyPI team are expected to follow the [PSF Code of Conduct](https://github.com/pypa/.github/blob/main/CODE_OF_CONDUCT.md). 

## Security vulnerabilities

**Do not report security issues in public forums or issue trackers.**

To read the most up-to-date version of the security policy, including directions for submitting security vulnerabilities, please visit [https://pypi.org/security/](https://pypi.org/security/).

## Individual user and project support

For issues concerning an individual user or project, or those that need intervention from an administrator or moderator, please open an issue in the [PyPI Support issue tracker](https://github.com/pypi/support). Examples of such issues include:

* **PEP 541 project name requests:** If a project is abandoned and you can't reach the owner, you can request the name under the guidelines of [PEP 541](https://peps.python.org/pep-0541/)  
* **Network access issues:** Problems with accessing PyPI services  
* **Upload limit requests:** If your project exceeds the default [storage limits](../project-management/storage-limits.md)  
* **Account recovery:** If you've lost access to your PyPI account

**Note:** By their nature, support issues are labor intensive. The PyPI team has limited resources available for their completion. There may be a delay of a week or more between responses to issues.

## Issues affecting all users

For issues that impact how PyPI functions, please open an issue in the [pypi/warehouse issue tracker](https://github.com/pypi/warehouse/issues) instead. These include:

* Feature requests  
* Usability issues  
* Bugs in PyPI itself

See [Contributing and Reporting Bugs](contributing.md) for more information.
